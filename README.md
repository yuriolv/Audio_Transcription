# 🎙️ Educational Insight & Student Performance Intelligence System

A **Python-based educational intelligence platform** developed in partnership with a language school.
Instead of performing raw audio transcription, this system processes **Zoom-generated class transcripts** and applies contextualized AI models to extract meaningful insights from unstructured data.

The goal is to transform classroom conversations into actionable academic intelligence — enabling deeper, individualized student monitoring.

---

## 📌 Overview

This project was designed to analyze transcripts generated by the class platform (e.g., Zoom) and convert them into structured, high-value educational insights.

The system:

* 📥 Ingests raw transcripts generated automatically by the class platform
* 🧠 Applies contextualized and fine-tuned AI models
* 📊 Extracts performance indicators from unstructured conversational data
* 👩‍🎓 Generates individualized student-level insights
* 💬 Provides a chatbot interface contextualized with recent student performance

Rather than focusing on speech-to-text, the core innovation lies in **unstructured data intelligence and educational analytics**.

---

## 🚀 Core Features

### 1️⃣ Transcript Intelligence Processing

* Structured parsing of Zoom transcripts
* Context-aware language model prompts
* Extraction of participation patterns
* Identification of strengths, weaknesses, and engagement levels
* Generation of summarized performance reports

---

### 2️⃣ Student Analytics Dashboard

* Individual student performance tracking
* Historical analysis of class participation
* Qualitative insight generation from conversational data
* Structured storage of extracted insights

---

### 3️⃣ Contextualized Student Chatbot

A dedicated student interaction module that:

* Uses the student’s recent performance data as context
* Provides personalized feedback
* Answers questions about progress
* Reinforces weak topics identified in transcript analysis

This transforms the platform from a passive analytics tool into an **interactive academic support system**.

---

## 🧠 Technical Architecture

The system follows a structured pipeline:

1. **Transcript Ingestion** – Import Zoom-generated transcript files
2. **Preprocessing** – Clean and structure conversational text
3. **Model Prompting Layer** – Inject contextual prompts tailored for educational insight extraction
4. **Insight Extraction** – Generate structured outputs from unstructured text
5. **Database Storage** – Store insights for longitudinal analysis
6. **Chatbot Context Engine** – Inject recent performance data into conversational responses

## 🧰 Getting Started

### 🔧 Prerequisites

* Python 3.8+
* Required dependencies (see `requirements.txt`)
* Zoom transcript exports for processing

---

### 📥 Installation

```bash
git clone https://github.com/yuriolv/Audio_Transcription.git
cd Audio_Transcription
pip install -r requirements.txt
```

Configure environment variables if necessary:

```bash
cp .env.example .env
# Add required configuration keys
```
